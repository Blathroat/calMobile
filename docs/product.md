# 产品行为

本文件是用户可见行为的来源。界面怎么实现见 [`engineering.md`](engineering.md)。部署见 [`operations.md`](operations.md)。服务端多出来的口径见 [`server/README.md`](../server/README.md) 的业务规则。

## 角色

- **普通用户**：浏览月历和详情、报名、取消报名、向展商申请私人会议、维护资料、查看公开主页。
- **访客**：未登录打开应用就先以访客身份落在首页看月历与当天展会，不再先显示登录页；只有需要登录的页面（我的活动、个人页、应用内的展会详情等）才跳登录页并带回原地址，登录页的「以访客身份浏览」仍回首页。访客能看到有展会的日期被加粗，看不到个人活动圆点。
- **展商**：管理自己的展会、报名收集项和报名审核；可核销自己展会的报名码；可开关私人会议预约、配置收集项并审核申请。展商身份可以是永久，也可以按天发放（见「注册、登录与安全」的邀请码）；到期后自动恢复为普通用户，已发布的展会与会议记录保留，管理员可以接管。
- **管理员**：管理用户、全部展会、各展商的私人会议、服务器设置、导出和审核策略。管理员同时拥有展商的全部能力，可以开办展会，也可以开关私人会议、配置收集项，并审核发给自己的申请。

## 账号状态

**正常 / 受限 / 封禁**是角色之外的账号状态。

受限账号可以登录、浏览、查询、审核已有报名和已有私人会议、改密码、管理通知偏好和撤销自己的报名。不能报名、不能提交新的私人会议申请、不能发布或修改展会、不能改报名设置或私人会议设置、不能核销或编辑个人资料。管理员不受此限制。封禁账号在认证层拒绝。

受限或封禁的展商不能接受新的会议预约，开关强制关闭。改回正常后开关保持关闭，直到展商自己重新打开。

## 注册、登录与安全

- 注册先校验用户名、邮箱和密码，再发验证码。验证码通过后才创建账号。验证码 10 分钟过期，单码最多尝试 5 次，用尽即作废。重发受冷却限制。注册页说明这些资料用于创建账号和发送验证码。配置了隐私政策地址时，同一段给出链接。
- 注册用户名允许中文、日文、韩文等 Unicode 字母、数字与组合符，以及下划线、点和横线；长度由管理员设置（默认 3–20），两侧空白自动去掉。内部空白、控制字符、标点与 emoji 不接受。登录框（用户名或邮箱）不受这个字符集限制。
- 注册页和用户设置都可以填写邀请码。有效邀请码会把身份设为展商；邀请码可以带展商时长（按天，0 表示永久，上限 10 年）：普通用户兑换后从兑换时刻起拥有这么多天展商身份。限时展商可以再兑换邀请码续期，新的时长从原到期日往后顺延；用 0 天邀请码兑换会转为永久。永久展商与管理员不消耗邀请码，邀请码也不能把人设成管理员。没有邀请码时，注册仍是普通用户。无效、过期或用完的邀请码会拒绝这次操作。受限账号不能兑换。展商时长走完后自动恢复为普通用户：不能再发布或修改展会、改报名设置、核销和接受会议预约，已发布的数据保留，可以再兑换邀请码恢复。
- 登录接受用户名或已验证邮箱。两步验证为「关闭 / 通行密钥（推荐）/ TOTP / 邮箱验证码」。通行密钥用设备的指纹、面容或锁屏密码确认登录，不需要输入验证码；绑定前要先通过一次身份复核（与绑定验证器相同），绑定成功后可以在安全设置里看到并删除。**当前两步验证方式是通行密钥时，不能删除最后一枚凭据**，要先切换到其它验证方式。通行密钥在应用里由系统凭据提供方（Android Credential Manager）完成，在浏览器里由 WebAuthn 完成；设备没有可用凭据提供方时，安全设置里说明原因并禁用添加入口。两步验证方式是通行密钥时邮箱验证码通道关闭：登录第二步只摆「使用通行密钥登录」，没有备用码时不再摆一个点了必然失败的验证码输入框；有备用码时给备用码输入（XXXXX-XXXXX），设备用不了通行密钥就提示换一台已绑定的设备或用备用码。**备用码是丢掉设备后的唯一退路**：切到通行密钥时如果还没有备用码，服务端顺手补 10 枚并当场展示一次（已有备用码时一枚都不动，不会悄悄作废旧码）；安全设置里没有备用码时给出警告并把动作改成「生成备用码」，只剩两枚以内时提醒重新生成；每枚只能用一次，关闭两步验证后保留未用的码。TOTP 不再标「推荐」。开启时密码通过只返回一次性预认证票，不发访问令牌。选定方式或备用码通过后才建立会话。注册设备默认记为可信设备。其他设备可在登录验证时选择以后免验证。安全设置可查看设备并远程下线单台或全部设备，时间使用中文日期格式。
- 访问令牌过期时先自动续期。刷新令牌被拒绝，或续期后的令牌仍被拒绝，清除会话，回登录页并保留原地址。网络暂时不可用不清除会话。
- 邮箱是身份。改邮箱先通过当前账号的身份复核，再把验证码发到新地址，验证后才落库。修改密码、新增或轮换 TOTP 也先复核。已绑定 TOTP 时复核可选 TOTP 或当前邮箱验证码。未绑定 TOTP 时只显示邮箱验证。复核票限定当前登录会话与操作，五分钟失效，只能使用一次。错误 TOTP 每会话 15 分钟最多五次。
- 密码、邮箱、TOTP 和两步验证开关都在安全设置里完成。关闭两步验证会保留已配置 TOTP 和备用码，再次启用 TOTP 时可一键恢复。轮换只有新验证码验证成功后才替换原密钥。修改密码后所有会话撤销并回到登录页。
- 忘记密码不泄露邮箱是否注册。重置成功后撤销该账号全部会话并清除可信设备。

## 用户协议

用户协议是可选的。管理员在「管理-设置 → 用户协议」里打开开关并上传 Markdown 文件作为正文后，登录页、注册页、用户设置页才会出现协议入口；关闭开关时这些入口全部隐藏，直接打开协议详情页只显示「暂未开启」。

- 开启后，登录页与注册页在提交前显示「我已阅读并同意《用户协议》」勾选框，《用户协议》是蓝色链接，未登录也能打开协议浏览页。未勾选时不能发送验证码、不能登录（含两步验证与通行密钥）或注册。
- 用户设置页最底部有「查看用户协议」入口；协议浏览页显示版本与更新时间，以及清洗后的 Markdown 正文。
- 报名站的登录页与注册页同样出现勾选与协议蓝链，协议浏览页同样可看；浏览器里选「不同意并退出」时网页无法自行关闭，会提示手动关闭页面。
- 每个账号记录自己同意到哪一版：注册成功、勾选同意的登录会记下当前版本。管理员只拨开关不会产生新版本，**正文更新才会升一版**：已登录用户下次进入应用（或重新登录）会看到不能跳过的确认窗口，可以查看协议、同意或「不同意并退出」。选不同意会关闭应用（浏览器里尝试关闭页面，关不掉时提示手动退出）；同意后记录新版本，窗口不再出现。
- 管理后台的用户卡片会标明每个账号是否已同意当前版本（显示同意到的版本与时间），方便管理员核对。

## 应用更新与下载

- 管理员在「设置 → 软件包下载」里选下载源：**GitHub 仓库**（服务器读取该仓库最新 Release，取以 `.apk` 结尾的资产作为下载地址，更新日志取该 Release 的说明）、**直链**（直接填 APK 地址，没有更新日志）或**目录**（填一个包含版本化 `.apk` 的目录，服务器读取 `index.json` 或目录列表，按文件名版本号选最新一版；同目录的 `latest.json` 可提供更新日志）。
- 用户设置最底部的「应用更新」组有「检查更新」和「自动检查更新」。检查更新读取服务器解析出的最新版本与下载地址：有版本号时（GitHub 或目录）版本比当前安装版本新才提示，直链文件没有版本号时只要有地址就可以下载。发现新版本时弹出抽屉，显示版本、更新日志（如有）和「下载并安装」；下载交给系统浏览器完成安装。自动检查更新是**本机偏好**，打开后每次进入应用在后台检查一次（六小时内不重复），同一个版本只自动提示一次。
- 浏览器报名站在**非应用内**打开时，顶部显示一条安装应用的悬浮条，应用内不显示。Android 与其它平台指向管理员配置的下载源；iPhone 没有 APK，改成「在 iPhone 上使用完整应用 / 查看安装方法」，打开安装到主屏幕的说明，不看有没有配下载地址。这条提示常驻，不提供关闭。

## 展会与报名

展会包含名称、地点、开展与闭展日期、时间、分类、报名方式、报名窗口、Markdown 简介、收集项和报名注意事项。分类必填；开展时间选填，留空表示只展示日期：列表、详情、分享文案和「加入日历」都只有日期，不留多余分隔符。编辑页把封面、纯文本简介、Markdown 编辑入口与「参与方式（仅通过审核用户可见）」收在同一张「活动信息」卡片：展商填写的参与方式只在报名者审核通过或已参加后，出现在该报名者的报名详情页；留空则不显示。封面区提示支持 3:4～9:16 的纵图。闭展日期选填，留空表示单日展会；填了就不能早于开展日期。详情与分享文案里的日期是开展～闭展的区间（单日只显示一天）。管理员可以设置单个展会最长持续天数（0 表示不限，按开展～闭展含两端算），超过上限时展商不能保存展会。报名方式为需审核、无需审核、仅展示、截止报名和已结束。

编辑展会时，开展与闭展是一组日期，点任意一侧打开应用内的「选择日期」抽屉，在一张月历上把起止一次选完（区间两端分别标「开展」「闭展」，中间日期浅色高亮）；报名开始与截止用同一套抽屉（两端标「开始」「截止」，可以只填开始，也可以清空）。两次点在同一个日期上表示区间只有这一天：开展与闭展（或开始与截止）两个框都显示这一天。开展时间分成开始与结束两个时 / 分滚轮，滚到哪选哪，攒成 `09:00-17:30` 这样的区间；两个都填才组成区间，都不填表示不设置时间（选填）。编辑页与私人会议都不再使用系统原生的日期、时间控件。

收集项支持文本、单选、多选和必填。没有收集项时报名页只显示提交按钮。单选和多选可以只有一个选项。展会和私人会议共用同一套收集项。前后端都按管理员下发的长度上限校验。

文字长度按展会信息、收集项文字、账号资料分成三组。收集项单独限制文本框标题（文本、单选、多选的标题共用）、文本框填写、单选选项和多选选项。编辑页的输入框按这个上限截断，保存和报名提交时前后端都会再拦一次。整段报名内容按所有回答拼在一起后的总字数计，含每项标题。这个总上限要大于单个文本框的上限，否则填满一个文本框也会被拒绝。空项在文稿里写成「未填写」，详情、审核和会议收件箱显示为「—」。

报名信息页的单选：所有选项都能在一行里显示完就排成一行；有一项放不下就改成每项独占一行，文字靠左。多选始终每项一行。独占一行仍然放不下时，按钮增高并把文字换行。私人会议申请页用同一套排法。

持续多天的展会（闭展晚于开展）在报名信息页多一行「参加时间」：两个日期按钮打开同一个范围抽屉，可选范围限制在开展～闭展之间；默认整段展期，可以改窄，也可以清除（表示不指定，按整段处理）。这段区间随报名一起保存，展商在报名详情里看到，报名人自己的报名详情也显示一行「参加时间」。单日展会没有这一行，也不提交这两个日期。

无需审核的报名直接通过。其他可报名状态进入待审核。状态为待审核、已通过、已拒绝、已参加或已撤销。已参加是终态，本人不能再撤销；管理员打开「允许展商修改已参加的报名」后，展商可以把已参加改回已通过或已拒绝，管理员始终可以改。待审核的报名可以撤销。已通过的报名在「通过后允许撤销报名」打开时可以撤销，这项默认打开。管理员没开「允许修改已通过或已拒绝的报名」时，展商不能改已通过、已拒绝或已撤销的记录。管理员不受这条策略限制。服务端还接受哪些状态跳转，见 [`server/README.md`](../server/README.md) 的业务规则。

简介以 Markdown 保存，渲染前清洗。活动信息卡里的简介文本框直接编辑这份源码（纯文本），与「使用Markdown编辑简介」打开的二级编辑器是同一份内容：从表单进二级编辑器时带过去的正文就是文本框里当前的文字，二级编辑器保存后回到编辑页即显示新正文。封面和简介里的图片、视频先在设备上选择，再上传到服务器。编辑器里打不开的会从正文去掉。新建展会时就能编辑简介。编辑简介的二级页面不再在正文上方重复显示展会标题，顶部只由外壳顶栏负责。二级编辑器在正文下方提供预览和粘贴 Markdown：预览打开后文案改为「继续编辑」，再点回到编辑。编辑展会时「删除展会」在页面内容最下方，保存固定在页脚。

报名详情对审核通过或已参加的报名展示「注意事项」卡片；待审核、已拒绝、已撤销不展示。这段正文由展商在「活动信息」卡的「参与方式（仅通过审核用户可见）」里填写（选填，最多 2000 字），留空不显示。

报名二维码可由展商启用，核销后报名变为已参加。只有「已通过」的报名能核销。重复核销会标明已经核销过。报名码必须属于这场展会。展商只能核销自己展会的报名码。报名被退回重审（已参加改回已通过或已拒绝）后会换一个新报名码，之前那张码随即失效，用户重新打开报名详情即可拿到新码。核销页用摄像头扫码；摄像头不可用时可改选一张图片扫码，或直接输入报名码。报名详情里的二维码可以长按保存成图片。核销成功的结果卡片留在核销页，刷新或重开页面后仍在，直到点顶栏的清理图标；卡片逐行列出报名收集项，并给出精确到秒的核销时间。

展商后台每张展会卡片右侧有二维码分享按钮：打开「分享展会」抽屉展示这条分享地址的二维码，可保存为透明背景、黑色点的 PNG（文件名 `exhibition-qr-<展会 id>.png`）；没配报名站地址时不打开空二维码，只提示未配置。卡片上的「复制链接」点击即复制，成功或失败都只用轻提示，不再弹让用户手动复制的面板。

用户已经报过这场展会时，展会详情页底部按钮变成「查看我的报名」，点它进入该报名的详情页；报名撤销后按未报名处理。

展会没有自己上传封面时，列表回退到管理员设置的缺省展会封面。详情页不展示缺省封面：没有自己上传的海报时，海报区与点开大图的入口整块不显示，也不画占位图。

海报在列表里的缩略图高度一致、宽度随海报本身的竖版比例变化：比例在 9:16 到 4:3（纵向）之间时按真实比例展示；超出这个范围（横幅或特别长的长图）按最接近的一端比例裁切填满，不把卡片撑高或撑成横图。详情页与点开后的灯箱等比完整展示整张海报，高度随海报比例，不裁切。

每位展商可同时筹备的展会数由管理员设置（0 表示不限），按「展会日期在今天及以后」计数。满额时不能新建未来展会，也不能把历史展会改到今天或以后。历史录入和已有未来展会的编辑不新增占用。管理员不受此限制。并发创建与改期遵守同一额度。单个展会最长持续天数也在同一张「展商相关」设置卡里配置（0 表示不限）。

首页月历里，有展会的日期数字更粗、略大，并用主题色。一场跨多天的展会在开展～闭展的每一天都算「有展会」：整段区间内的日期都会加粗，选中其中任意一天，下面都会列出这场展会。左右滑动月历卡片可以切月：拖动时卡片跟手，两侧露出上/下个月的日历预览；松手超过阈值才切月，没到阈值弹回。切月后按新月份的数据重画。选中日用深一档的主题色和下划线。日期下方的标题是「X 月 X 日的活动」。当天列表里的展会卡片依次是标题与报名方式、时间与地点、展商名称与分类；没设置时间时只显示地点。列表先放当天展会，再放本人相关的私人会议卡片：待审核和已通过都显示，申请人看到主办人，主办人看到申请人。已拒绝和已撤销的会议不显示。圆点出现在：用户已通过或已参加的报名日期（多天展会按报名时选的参加时间，没选就按整场）、用户待审核或已通过的私人会议日期、自己开办的展会日期、自己待审核或已通过的私人会议日期。已拒绝和已撤销不打点。管理员与展商一样算主办人。

## 私人会议

链接形如 `{PUBLIC_BASE_URL}/m/{主办人 id}`。打开后进入报名站的申请页，仍然要注册并登录。没配 `PUBLIC_BASE_URL` 时不编造本机地址。

设置包含「是否接受会议预约」、「通过后允许撤销」、申请页说明，以及与展会相同的收集项。申请地址在设置里，列表底部也有同一行；页顶那一行右侧有复制与二维码两个按钮，二维码打开与展商分享展会相同的抽屉，可以保存成图片，没配报名站地址时只提示未配置。说明显示在申请页主办人名称下方，留空则不显示。

申请页的日期和时间放在同一行。日期必填且不能早于今天，点开应用内的单个日期抽屉选；时间选填，用小时 / 分钟滚轮选，格式是 HH:MM。

普通用户在展商或管理员的公开主页发起申请。对方未开启、账号受限或封禁、以及不能开办会议时，按钮为灰色，文案是「展商暂不接受会议预约」。不能向自己预约。同一访客、同一主办人、同一天只能有一条待审核或已通过的申请。被拒绝后可以再约。

申请先进入待审核，由展商通过或拒绝。待审核、已通过、已拒绝和已撤销都出现在用户的「我的活动」里。首页当天列表和圆点只含待审核与已通过。待审核可以撤销。已通过只有主办人打开「通过后允许撤销」才能撤销。没有会议核销。展会报名同样有「通过后允许撤销报名」，默认打开，所以已有的已通过报名仍可撤销。

展商可同时筹备的私人会议数由管理员设置（0 表示不限），按「会议日期在今天及以后，且状态为待审核或已通过」计数。满额后新申请失败。拒绝、撤销或删除后空出名额。管理员代为提交也占额度。

报名管理和私人会议里的用户卡片：待审核时是「通过 / 拒绝」。状态为已通过、并且当前身份还能改这条报名时，卡片上有「标记为已参加」，旁边仍是「查看详情」。展商在管理员没开「允许修改已通过或已拒绝的报名」时看不到这个按钮。其它已审完的卡片只剩「查看详情」。再改状态从详情进入，按钮文案是「调整状态」。展商不能改已审核报名时，说明写「该报名已完成审核，管理员不允许重新审核。」被限制的会议，主办人的通过和拒绝不可用。管理员在会议详情里可以限制或解除限制，以及删除会议。

展示某个人时，展商和管理员的名字后有角色标签，普通用户没有。首页会议卡片标的是标题里那个人：申请人看到的是主办人，主办人看到的是申请人。管理页点用户卡片主体进入公开页。每张用户卡片都有「调整权限」。普通用户的按钮是「调整状态」「调整权限」。展商和管理员是「管理展会」「管理会议」「调整状态」「调整权限」。点「调整权限」弹出抽屉，选项是用户、展商、管理员。不能改自己的权限，也不能去掉最后一位管理员。把展商或管理员改成普通用户时，私人会议开关会关掉。管理展会打开该主办人的全部展会。管理页用户名单只显示昵称。搜索结果里，普通用户的名字后写角色文字。展商和管理员用角色标签表示身份。

## 浏览器报名站

未安装应用的人用浏览器完成注册、登录（含找回密码和已开启的两步验证）、展会报名、查看自己的报名，以及申请私人会议。报名站没有月历、展会目录、资料、设置、展商后台、核销和管理后台。

- 报名地址是 `{PUBLIC_BASE_URL}/e/{展会 id}`。私人会议申请地址是 `{PUBLIC_BASE_URL}/m/{主办人 id}`。没配域名时不生成 `127.0.0.1` 链接，并说明报名站地址未配置。能打开详情的人分享展会时带上报名地址。
- `/` 未登录进入登录页，已登录进入「我的活动」。对不上的地址说明请使用展商分享的链接，并可去登录或我的活动。
- 分享链接先打开展会详情页，**未登录也能看**。这一屏显示封面、标题、日期时间、地点、报名方式和清洗后的简介，底部只有一颗「立即报名」，没有「加入日历」。点展商卡片查看公开页要先登录，登录后回到该公开页。宽屏仍是居中单列，最大宽度 720px。
- 点「立即报名」不需要登录，进入报名信息页。未登录时按匿名报名处理姓名：展商的收集项里有标题命中管理员配置的姓名同类词（默认「姓名 / 昵称 / 称呼 / 圈名」）的文本项时，直接拿它当姓名，不再单列姓名输入（匿名报名时这一项一律必填，标题按展商配置的原文显示）；没有命中的收集项时，收集项上方多一项必填「昵称」。其余收集项照旧；已登录的报名站用户按账号报名。「我的活动」仍是账号的报名列表。
- 未登录提交后进入报名状态页：显示展会、报名信息、状态与报名码（展商开启二维码且已通过时），并额外显示「查询报名状态」链接和复制按钮。**这条链接是未登录时查询报名详情的唯一凭据，必须保存好**，丢失后无法找回。
- 状态页未登录时页脚没有「修改报名 / 撤销报名」，改为「登录 / 注册」：登录或注册后回到状态页，并把这条报名关联到账号（之后进入账号自己的报名详情，页脚恢复修改与撤销）。关联失败（例如已被别的账号关联，或与该账号已有同展会的报名）会说明原因，仍可用链接查看。应用内报名流程与展示不变：应用内报名要求登录，成功后回「我的活动」。
- 「我的活动」为空时提示通过展商发给的链接报名，或预约私人会议。退出登录在这一页的顶栏。刷新页面后仍保持登录：没有原生桥时，刷新令牌存在本机 `calmobile.session`。应用里仍只存设备私有存储。

## iPhone / PWA

iPhone 不提供 APK。用 Safari 打开完整应用地址 `{PUBLIC_BASE_URL}/app/`（没配对外域名时安装说明用当前域名），点分享 →「添加到主屏幕」，主屏幕上的图标会以独立窗口打开完整应用：月历、展会详情与报名、展商后台、核销、管理后台和设置都在，账号与数据与 Android 应用相同。

- 安装入口：iOS 浏览器打开完整应用时（还没装到主屏幕），首页在首屏之后提示一次「安装到主屏幕」，关掉后记在本机、不再自动出现，已经安装（从主屏幕启动）时也不会出现；设置页同样只在 iOS 未安装时显示「安装到主屏幕」入口，可以再看步骤。步骤里显示完整应用地址和复制按钮，报名站打开时还可一键「打开完整应用」。非 Safari 的 iOS 浏览器（微信等内置浏览器、Chrome 等）不能直接添加，说明会提示先用 Safari 打开。
- 安装后第一次打开可能需要重新登录：主屏幕应用是独立的浏览器存储，不继承 Safari 里的登录状态；账号、报名与其它数据都在服务器上，重新登录后照旧。
- 设备能力改用浏览器接口，页面入口与结果保持一致：头像、封面和简介里的图片从系统文件选择器选择，先在页面上转成 JPEG 再上传；视频同样从文件选择器选择；语言包与用户协议 Markdown 文件从文件选择器读取；CSV 导出、语言包底稿与二维码图片改成浏览器下载（二维码保存到「文件」而不是相册）；文本分享走系统分享面板，没有分享面板时退回复制并提示已复制；「加入日历」生成 `.ics` 文件，能分享时打开系统分享面板（存到「文件」后打开即可加入日历），不能分享时直接下载，且不提供「移出日历」；核销扫码用浏览器摄像头取景，取景不可用时照旧改选图片或手动输入报名码；通知权限走浏览器的权限申请。只在原生壳里存在的动作（把媒体落盘到设备目录、把外观镜像给原生）不向浏览器提供。
- 没有 APK 更新：设置页不出现「应用更新」，没有检查更新、自动检查更新与下载安装。页面包在下次打开时更新；重新打开主屏幕应用就会用上新版本。
- 没有推送：通知仍只有账号里的通知开关与记录，不弹系统推送。
- 没有离线数据：页面壳（界面与静态资源）可以离线打开，但月历、展会、报名、资料等数据仍要联网；后端不可用时与其它客户端一样报错。
- 主屏幕名称与图标来自安装时的页面清单，清单在构建时按中文文案生成；安装后切换语言包不会改主屏幕名称。要改名称或图标，需要在主屏幕上删掉图标，重新用 Safari 打开 `/app/` 再「添加到主屏幕」。

## 个人与管理

个人页先展示身份卡：头像、昵称、角色与账号状态，账号状态正常时不单独显示，受限或封禁时才标出来；身份卡底部是活动概览，显示已参加场数与报名记录条数，点一下进入我的活动。下面依次是个人简介（保留换行；没有简介时显示「还没有简介」与可点的「填写简介」，不把操作指引当正文）、公开资料（地区、社交账号，空值显示「未填写」），以及「查看公开主页」「设置」「安全设置」三个入口，最底部是退出登录。身份卡右侧的铅笔和顶栏「设置」打开同一个资料编辑抽屉；头像的更换、移除就在抽屉最上方，选完图裁剪好立即保存，不必再点抽屉的「保存」。个人页身份卡与设置页的身份卡只展示头像。在应用里选头像是打开系统相册（Photo Picker），浏览器里退化成文件选择。查看公开主页打开自己的公开页，入口右侧写明公开页是展示报名记录还是只展示资料。默认语言跟随服务器配置的默认语言包，应用与报名站一致；用户在设置里显式选择过则优先，默认包未安装或下载不到时回退中文。跟随服务器默认语言时，服务器上的默认包换了新版本会覆盖本机那份，重载后整页用新译文；用户显式选过语言的包不会被自动换掉。设置页按账号、通知与隐私、外观、语言、邀请码分组：账号组放身份展示、编辑资料入口与受限说明（头像在编辑资料抽屉里改）；通知与隐私组放两条通知开关、系统通知权限与报名公开展示；外观组放应用配色与明暗模式；语言组可以切换语言、粘贴链接或选择 JSON 文件安装，安装成功后重载成新语言并给出提示，重载期间不会先跳回登录页；「下载中文底稿」在应用里由系统「另存为」保存到用户选的位置。邀请码卡片在语言组之后、应用更新之前：普通用户显示输入框，通过后身份变为展商；限时展商同样显示输入框，并写明当前到期日与顺延规则；永久展商与管理员只显示「不需要邀请码」的身份说明。限时展商在个人页身份卡里看到「展商有效期至某日」，7 天内到期与到期后都会给出续期提示。安全设置只从个人页进入，密码、邮箱与两步验证在那里完成。报名管理的用户卡片显示姓名与报名时间，不再显示报名摘要。

用户公开页展示身份卡（头像、昵称、角色与已参加展会数）、公开资料与已参加展会。已参加展会数是公开事实，不受「展示我的报名」开关影响；开关只决定下方报名记录列表是否展示。管理员从管理后台进入时不受该开关限制，页面会标明管理视角；管理员视角下昵称右侧有一颗小铅笔，点开可代改这个用户的昵称、简介、地区和社交账号。

应用配色有 12 种可选，色板用描边与对勾标出当前选择，点一下即生效；配色与明暗模式按账号保存，换设备跟随账号。管理后台只维护全局默认色板、品牌文案与服务器设置；审核策略里可以打开「允许展商修改已参加的报名」，服务器设置用页面右下角的悬浮保存按钮保存。「管理-设置 → 报名相关」里可以编辑匿名报名的姓名同类词（一行一个，默认 姓名 / 昵称 / 称呼 / 圈名；清空表示不合并、仍单列姓名）。落库和首帧见 [`engineering.md`](engineering.md)。

管理-设置的「日志」卡片里有「查看最近日志」按钮（整行浅色描边按钮，位于上限设置下方），进入只读的最近日志页：顶部显示服务器已存日志条数与已用空间 / 上限，下面列出最近 100 条日志（时间、级别、消息、分类、操作人、IP 与 HTTP 状态码），可按全部 / 信息 / 警告 / 错误筛选并下拉刷新。日志记录管理操作、登录 / 注册结果与失败请求，不记录请求正文。管理-设置的「日志」卡片可以设置日志存储上限（MB，1～10240，默认 64）并显示当前条数与已用空间，超过上限会自动清理最早的日志。

管理后台按用户、展会和设置分区。用户分区可以按身份（全部 / 普通用户 / 展商 / 管理员）与账号状态（全部 / 正常 / 受限 / 封禁）筛选，筛选写进地址栏，可以跟昵称 / 用户名 / 邮箱搜索叠加。展会管理与系统设置留在管理后台里。核销从展商后台进入。设置里能看到服务器上的头像和展会媒体占了多少空间，并设置上限。存满以后默认不允许新上传，也可以改成清掉最早的文件。设置里还可以生成邀请码：填写可使用次数、有效小时（0 表示不过期）和展商时长（天，0 表示永久），生成后列出仍可用或已用完的邀请码，每行写明时长与状态，可以复制或删除。用户管理里限时展商显示到期日，已到期的显示「展商已到期」。过期的码在列表时被清掉，不再显示。用户管理卡片的「最近登录」显示日期与该次登录 IP 所属地区（如「最近登录 2026-11-17 江苏省苏州市」；来自内网显示「内网」，取不到地区只显示日期），每次登录都会刷新这一行（密码登录、两步验证通过、通行密钥、注册建号都算一次），经过 Cloudflare 转发时按用户真实地址解析地区；账号状态只在卡片右侧显示一次，这一行不再重复状态。注册成功即算一次登录，新注册用户不会显示「未知」，没有登录记录的老账号按注册时间显示。展商与管理员的报名审核在触发卡片附近的面板完成。点头像进入该用户的公开页，点卡片其他地方打开报名详情。用户分区点卡片主体进入公开页。

一次性提示（首页「左右滑动日历卡片可以切换月份」、展商后台的核销说明）显示到用户做完对应动作为止。滑动过日历、进过核销页，或点「知道了」都会记到账号上，之后换设备也不再出现。

底部导航的选中项只把图标与文字换成主题色并加粗，不画下划线或滑动指示条。必填项没填就保存时，字段换成浅色校验底色并轻轻抖一下，错误文案淡入；系统开启减少动效时这些动画不播放。页面提供空、加载、错误、成功和禁用状态，并保留用户下一步操作。下拉刷新的加载圈只在用户明确下拉时出现：切换页面、后台更新都不播这枚动画，点击链接时的轻微滑动也不会触发。

## 当前限制

- 应用必须连接后端，没有离线数据层（iPhone 主屏幕应用只把页面壳缓存在本机）。头像、展会封面和简介里的图片、视频上传后保存在服务器，换设备仍能看到。没有被引用或已经打不开的文件会删掉。
- 应用图标是构建期配置（`APP_ICON` / `APP_ICON_BACKGROUND`），管理员不能在应用内修改；换图标要重新构建页面和 APK，已安装的主屏幕或桌面图标需要重新添加或重装后才更新。
- 视频只校验大小和后缀，不转码。通知只有数据库记录和权限申请，没有推送通道。
- 域名、TLS 和邮件中继见 [`operations.md`](operations.md)。
