# 产品行为与验收

本文件是用户可见行为、验收场景和当前限制的来源，只描述当前状态。后端状态码、数据库和实现细节见 [`server/README.md`](../server/README.md)；界面实现见 [`engineering.md`](engineering.md)。

## 角色与账号状态

- **普通用户**：浏览月历和详情、报名、取消报名、向展商申请私人会议、维护资料、查看公开主页。
- **访客**（未登录点「以访客身份浏览」）：只能待在首页看月历与当天展会，其它页面会被送回登录页并带上原地址。访客能看到有展会的日期被加粗，看不到个人活动圆点。
- **展商**：管理自己的展会、报名收集项和报名审核；可核销自己展会的报名码；可开关私人会议预约、配置收集项并审核申请。
- **管理员**：管理用户、全部展会、各展商的私人会议、服务器设置、导出和审核策略。管理员同时拥有展商的全部能力，可以开办展会，也可以开关私人会议、配置收集项，并审核发给自己的申请。
- **正常 / 受限 / 封禁**是角色之外的账号状态。受限账号可以登录、浏览、查询、审核已有报名和已有私人会议、改密码、管理通知偏好和撤销自己的报名；不能报名、不能提交新的私人会议申请、不能发布或修改展会、不能改报名设置或私人会议设置、不能核销或编辑个人资料。管理员不受此限制；封禁账号在认证层拒绝。受限或封禁的展商不能接受新的会议预约，开关强制关闭；改回正常后开关保持关闭，直到展商自己重新打开。

## 核心行为

### 注册、登录与安全

- 注册先校验用户名、邮箱和密码，再发验证码；验证码通过后才创建账号。验证码 10 分钟过期，重发受冷却限制。
- 登录接受用户名或已验证邮箱。两步验证常驻为「关闭 / TOTP（推荐）/ 邮箱验证码」三选一；开启时密码通过只返回一次性预认证票，不发访问令牌，选定方式或备用码通过后才建立会话。注册设备默认记为可信设备；其他设备可在登录验证时选择以后免验证。安全设置可查看设备并远程下线单台或全部设备，时间使用中文日期格式。
- 访问令牌过期时先自动续期；刷新令牌被拒绝或续期后的令牌仍被拒绝时清除会话，回登录页并保留原地址。网络暂时不可用不清除会话。
- 邮箱是身份。改邮箱必须先通过当前账号的身份复核，再把验证码发到新地址，验证后才落库；修改密码与新增 / 轮换 TOTP 也须先复核。已绑定 TOTP 时复核可选 TOTP 或当前邮箱验证码；未绑定 TOTP 时只显示邮箱验证。复核票限定当前登录会话与操作、五分钟失效且只能使用一次，错误 TOTP 每会话限试五次。
- 密码修改、邮箱变更、TOTP 绑定 / 轮换、两步验证开关都在安全设置抽屉完成。关闭两步验证会保留已配置 TOTP 和备用码，再次启用 TOTP 时可一键恢复；轮换只有新验证码验证成功后才替换原密钥。修改密码后所有会话撤销并回到登录页。
- 忘记密码不泄露邮箱是否注册；重置成功后撤销该账号全部会话并清除可信设备。

### 展会与报名

- 展会包含名称、地点、日期、时间、分类、报名方式、报名窗口、Markdown 简介和收集项。报名方式包括需审核、无需审核、仅展示、截止报名和已结束。线框里的「现场亮点」标签组**不实现**：它没有编辑入口，只能是示例数据里的摆设，已从详情页、接口、示例数据和表结构里移除。
- 报名收集项支持文本、单选、多选和必填；没有收集项时报名页只显示提交按钮。前后端都按管理员下发的长度上限校验。编辑时所有收集项排在同一张卡里，用分隔线隔开，不再套子卡片。相邻两项的标题上方多留一截空白，方便看出分隔。标题占一整行，左上角嵌着名称；类型是同一行下方的滑动分段，在文本、单选、多选之间切换。说明和选项更小、更淡，选项是紧凑输入框。单选和多选可以只有一个选项。必填是底行左侧的勾选，删除在底行右侧。展会和私人会议用同一张卡。编辑展会时「删除展会」在页面内容最下方，保存仍固定在页脚。
- 管理设置里的文字长度按展会信息、收集项文字、账号资料分成三组。收集项单独限制文本框标题（文本、单选、多选的标题共用）、文本框填写、单选选项和多选选项。编辑页的输入框按这个上限截断，保存和报名提交时前后端都会再拦一次。整段报名内容是所有回答拼在一起后的总字数，含每项标题；它要比文本框填写大，否则填满一个文本框也会被拒绝。空项在文稿里写成「未填写」，详情、审核和会议收件箱显示为「—」。
- 报名信息页的单选：所有选项都能在一行里显示完就排成一行；有一项放不下就改成每项独占一行。文字靠左。多选始终每项一行。独占一行仍然放不下时，按钮增高并把文字换行。私人会议申请页用同一套排法。
- 无需审核的报名直接通过；其他可报名状态进入待审核。审核状态为待审核、已通过、已拒绝、已参加或已撤销；已参加是终态。
- 简介以 Markdown 保存，渲染前清洗。封面和简介里的图片、视频先在设备上选择，再上传到服务器；编辑器里打不开的会从正文去掉。新建展会时就能编辑简介，不必先保存出展会。编辑页下方只有预览和粘贴 Markdown：预览平时是浅色按钮，点开后变成主题色，文案改为「继续编辑」，再点回到编辑。报名二维码可由展商启用，核销后报名变为已参加。
- 展会没有自己上传封面时，列表与详情回退到管理员设置的**缺省展会封面**；缺省封面也为空时显示占位图。
- 每位展商**可同时筹备的展会数**由管理员设置（0 表示不限），按「展会日期在今天及以后」计数。满额时不能新建未来展会，也不能把历史展会改到今天或以后；历史录入、已有未来展会的编辑不新增占用，管理员不受此限制。并发创建与改期也遵守同一额度。
- 首页月历里，**有展会的日期数字更粗、略大，并用主题色**。选中日仍用深一档的主题色和下划线。日期下方的标题是「X 月 X 日的活动」。列表先放当天展会，再放本人相关的私人会议卡片：待审核和已通过都显示，申请人看到主办人，主办人看到申请人。已拒绝和已撤销的会议不显示。圆点出现在：用户已通过或已参加的报名日期、用户待审核或已通过的私人会议日期、自己开办的展会日期、自己待审核或已通过的私人会议日期。已拒绝和已撤销不打点。管理员与展商一样算主办人。

### 私人会议

- 展商在后台用与管理页相同的分段切换「展会 / 私人会议」。私人会议页先写「收到的申请」和计数，下面是「私人会议相关设置」。申请地址放在设置页顶部，右侧是小复制图标，说明是一行「发给对方，登录后即可申请。」列表页底部仍有同一行地址。管理员打开自己的后台时，处理的是发给自己的申请，底部地址栏同样是小图标。管理另一位展商或管理员，仍从用户卡片进入。链接形如 `{PUBLIC_BASE_URL}/m/{主办人 id}`，打开后进入报名站的申请页，仍然要注册并登录。没配 `PUBLIC_BASE_URL` 时不编造本机地址。
- 设置页顶部是申请地址。下面有「是否接受会议预约」开关、「通过后允许撤销」开关、申请页说明，以及与编辑展会相同的收集项卡片。申请页的日期和时间放在同一行，日期用日期选择，时间用时间选择；日期必填且不能早于今天，时间选填，格式是 HH:MM。说明显示在申请页主办人名称下方，留空则不显示。
- 普通用户在展商或管理员的公开主页发起申请。申请按钮是浅色样式，放在「公开资料」卡片下面，不再悬浮在页脚。对方未开启、账号受限或封禁、以及不能开办会议时，按钮为灰色，文案是「展商暂不接受会议预约」。不能向自己预约。同一访客、同一主办人、同一天只能有一条待审核或已通过的申请；被拒绝后可以再约。公开页不再放「返回首页 / 返回管理后台」，用左上角返回。
- 申请先进入待审核，由展商通过或拒绝。待审核、已通过、已拒绝和已撤销都出现在用户的「我的活动」里，点进去是会议详情。首页当天列表和圆点包含待审核与已通过，不含已拒绝和已撤销。待审核可以撤销；已通过只有主办人打开「通过后允许撤销」才能撤销。没有会议核销。展会报名同样有「通过后允许撤销报名」，默认打开，所以已有的已通过报名仍可撤销。
- **展商可同时筹备私人会议数**由管理员设置（0 表示不限），按「会议日期在今天及以后，且状态为待审核或已通过」计数。满额后新申请失败；拒绝、撤销或删除后空出名额。管理员代为提交也占额度。
- 报名管理和私人会议里的用户卡片：待审核时卡片上是「通过 / 拒绝」，审完后只剩一颗「查看详情」。再改状态从详情抽屉进入，按钮文案是「调整状态」。展商不能改已审核报名时，抽屉里写「该报名已完成审核，管理员不允许重新审核。」被限制的会议，主办人的通过和拒绝不可点。管理员的「限制会议 / 解除限制」和「删除会议」放在详情抽屉里，关闭单独占下一行。
- 凡是展示某个人的用户卡片，展商和管理员的名字后面有一枚蓝色小标签，文案分别是「展商」和「管理员」，样子与展会卡片上的「仅展示」相同。普通用户不显示这枚标签。首页会议卡片标的是标题里那个人：申请人看到的是主办人，主办人看到的是申请人。绿、黄、蓝状态标签与主题色标签一样，只用描边和彩色文字，字色是绿、黄、蓝。
- 管理页用户卡片不再单独放「公开页」按钮，点卡片主体进入公开页。普通用户只有「调整状态」。展商和管理员是「调整状态」「管理展会」「管理会议」，排成一行。管理展会打开该主办人的全部展会，卡片按钮与管理后台的展会分区相同。管理视角下，展商公开页在资料卡下面把「管理展会」和「管理会议」排成一行。管理页用户名单只显示昵称，普通用户名字后面不再写「普通用户」。搜索里，普通用户仍在名字后写角色文字。展商和管理员改由蓝色标签表示，不再重复「· 展商」。

### 浏览器报名站

未安装应用的人用浏览器完成注册、登录（含找回密码和已开启的两步验证）、展会报名，以及查看自己的报名。报名站没有月历、展会目录、资料、设置、展商后台、核销和管理后台。

- 报名站和后端同一个进程、同一个 `PORT`。开发默认托管；生产默认不托管，要对外提供时设 `ENABLE_WEB=true`（产物缺失则拒绝启动）。配了 `PUBLIC_BASE_URL` 时，页面请求的 Host 必须是这个域名，否则跳过去；`/api`、`/media`、`/ping`、`/health`、`/status` 不跳转，应用仍可连本机端口。没配域名时不跳转，本机地址是 `http://localhost:${PORT}/`。
- `/` 未登录进入登录页，已登录进入「我的活动」。对不上的地址说明请使用展商分享的链接，并可去登录或我的活动。
- 报名地址是 `{PUBLIC_BASE_URL}/e/{展会 id}`。私人会议申请地址是 `{PUBLIC_BASE_URL}/m/{主办人 id}`。展会卡片上「查看报名 / 编辑展会 / 复制链接」在同一行，点卡片进入展会详情。私人会议链接在设置页顶部和私人会议列表底部。能打开详情的人分享展会时带上报名地址。没配 `PUBLIC_BASE_URL` 时不编造本机地址，并说明报名站地址未配置。
- 报名页在原有表单上方显示封面、标题、日期时间、地点、报名方式和清洗后的简介。宽屏仍是居中单列，最大宽度 720px。
- 「我的活动」为空时提示通过展商发给的链接报名，或预约私人会议。退出登录在这一页的顶栏。刷新页面后仍保持登录：没有原生桥时，刷新令牌存在本机 `calmobile.session`。应用里仍只存设备私有存储。

### 个人、管理与界面状态

- 个人页展示头像、昵称、角色、地区、简介与社交账号，并给出一个设置卡片。简介标题右侧的铅笔打开与设置页相同的编辑资料抽屉。顶栏右侧的「设置」图标与这张卡片进的是同一页，头像裁剪、通知偏好、应用配色、明暗模式和**隐私开关**收在那里；密码、邮箱与两步验证操作集中在安全设置。
- 应用配色与明暗模式是**个人偏好**，按账号保存（换设备跟随账号），本机缓存一份用于首帧；管理后台只维护全局默认色板、品牌文案与服务器设置。
- 管理后台按用户、展会和设置分区。顶栏已经写着「管理后台」，分区切换上方不再重复这四个字。设置里能看到服务器上的头像和展会媒体占了多少空间，并设置上限。存满以后默认不允许新上传，也可以改成清掉最早的文件。展商与管理员的报名审核在触发卡片附近的面板完成。点头像进入该用户的公开页，点卡片其他地方打开报名详情。用户分区点卡片主体进入公开页。
- **一次性提示**（首页「左右滑动日历卡片可以切换月份」、展商后台的核销说明）显示到用户做完对应动作为止：滑动过日历、进过核销页，或点「知道了」都会记到账号上，之后换设备也不再出现。其余说明性文案已按反馈删掉，不再逐屏解释字段。
- 页面必须提供空、加载、错误、成功和禁用状态，并保留用户下一步操作的提示。

## 验收场景

1. 用户能在月历切换月份、按日期查看展会、进入详情并提交符合收集项的报名。
2. 仅展示、截止报名和已结束的展会明确说明不可报名；访客报名先登录，登录后回到原展会。
3. 展商能创建展会、上传 9:16 封面、配置收集项、编辑 Markdown 简介并在详情页看到渲染结果。
4. 展商或管理员能筛选报名、查看完整回答、执行允许的审核流转；无需审核自动通过。
5. 管理员改服务器设置或账号状态后，页面入口、校验和提示同步更新；用户改配色或明暗模式后立即生效并跟随账号。
6. 头像裁剪、深色模式、日历、分享、媒体选择、CSV 导出和扫码核销均能在设备能力可用时完成，失败时保留可解释错误。
7. 两步验证、改邮箱、找回密码和验证码重发遵守“一次性、过期、限流、未通过不发令牌”的规则。
8. 受限账号的入口置灰，深链也被后端拒绝；管理员仍能处理受限账号。
9. 未安装应用的人打开展商分享的报名链接后可以注册或登录、提交报名，并在「我的活动」里看到状态、回答和二维码；私人会议链接同样要求登录后才能申请。随意输入的地址不会变成展会目录。

## 当前限制

- 应用必须连接后端；没有离线数据层。头像、展会封面和简介里的图片、视频上传后保存在服务器，换设备仍能看到。没有被引用或已经打不开的文件会自动删掉。存储满了以后，按管理设置拒绝新上传，或先删掉最早的文件。
- 视频只校验大小和后缀，不转码；通知目前只有数据库记录和权限申请，没有推送通道。
- 服务当前按本地开发形态运行；对外部署仍需 HTTPS、域名、生产密钥、受保护的状态页和托管邮件中继，清单见 [`docs/operations.md`](operations.md)。
- 客户端缺少完整的 UI / Instrumentation 自动化回归；模拟器和真机流程见 [`docs/operations.md`](operations.md)。
