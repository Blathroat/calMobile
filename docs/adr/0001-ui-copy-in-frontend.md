# 界面文案放在前端模块

内置语言是中文，放在 `web/src/i18n/zh.json`。`t()` 按点分路径读取，例如 `auth.login.title`。别的语言缺条时回中文。用户安装的语言包在本机，不进页面包。报名站只有在服务器默认名称写进下载列表时才改用该语言。

界面曾经只有一种语言，句子放在 Android XML 里，打开页面时再注入。注入是异步的，顶栏会停在短码上。报名站还要把同一份 XML 在构建时再写进页面。改到前端之后，应用和报名站打进各自的包。Android 不再注入。邮件正文仍由后端书写。

## Considered Options

- 继续放在 Android XML，运行时注入。
- XML 仍是正文，但改成构建时写进页面。
- 引入 vue-i18n。

这三项都为一种语言、且没有插值和复数的界面多维护一条链路。Android 的语言目录目前没有第二种界面语言可用。
