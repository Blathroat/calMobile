# Triage Labels

技能用五个分流角色说话。本文件把这些角色映射到本仓库 issue tracker 里实际使用的标签字符串。

| Label in mattpocock/skills | Label in our tracker | 含义 |
| -------------------------- | -------------------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这条 issue |
| `needs-info`               | `needs-info`         | 等报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格已齐，可交给无人值守 agent |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不会跟进 |

技能提到某个角色（例如「打上 AFK-ready 分流标签」）时，用本表右列对应的标签字符串。

要改词汇，只改右列，与 tracker 里实际用的名字对齐。
